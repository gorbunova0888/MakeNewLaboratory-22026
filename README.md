# Лабораторная работа: Линейные алгоритмы (Кубическое уравнение)

## Автор
Горбунова Настя (Вариант 2)

## Цель
Освоение базового синтаксиса C++, работы с математической библиотекой `<cmath>` и реализация линейного алгоритма для решения кубического уравнения.

## Описание
Программа рассчитывает три действительных корня кубического уравнения вида \(x^3 + ax^2 + bx + c = 0\) с использованием тригонометрического метода Виета.

## Исходные данные
Пользователь вводит с клавиатуры три коэффициента уравнения:
- Коэффициент `a`
- Коэффициент `b`
- Коэффициент `c`

## Ожидаемые результаты
Программа выводит на экран три вычисленных корня уравнения:
- `x1`: первый корень
- `x2`: второй корень
- `x3`: третий корень

## Математическая справка (Используемые формулы)
Для приведения уравнения к неполному виду вычисляются:
- \(P = b / a\)
- \(g = c / a\)

Вспомогательный угол:
- \(\alpha = \arccos(-g / (2 \cdot \sqrt{-(P/3)^3}))\)

Корни вычисляются по формулам:
- \(x_1 = 2 \cdot \sqrt{-P/3} \cdot \cos(\alpha / 3)\)
- \(x_2 = -2 \cdot \sqrt{-P/3} \cdot \cos((\alpha + \pi) / 3)\)
- \(x_3 = -2 \cdot \sqrt{-P/3} \cdot \cos((\alpha - \pi) / 3)\)
